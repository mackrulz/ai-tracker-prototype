# AI Tracker – mobil prototip

Tıklanabilir mobil web prototipi (örnek veri). Herkese açık marka takibi: iş kategorisi siteden algılanır ("Diş hekimi olarak algıladık · Değiştir"), soru önerileri ve "hastaların / müşterilerin" metni kategoriye göre değişir.

Başlangıç platformları: ChatGPT, Gemini, Google AI Overviews, Google AI Mode. Claude ve Grok kilitli (Standart'ta açılır).

Canlı (repo herkese açıkken): https://mackrulz.github.io/ai-tracker-prototype/
